| **B01 — Direct evidence reading** | Retrieve a fact explicitly stated in readable document content. | “জারিকারী কর্তৃপক্ষ: জেলা শিক্ষা অফিস।” | “নোটিশটি কে জারি করেছে?” → জেলা শিক্ষা অফিস। |

| **B04 — Claim verification** | Classify a claim as supported, contradicted or insufficient information relative to the document. | “করিমের বর্তমান শিক্ষাপ্রতিষ্ঠান: RUET।” | “করিম RUET-এ পড়ে” → supported; “করিম RUET-এ নয়, KUET-এ পড়ে” → contradicted; “রহিম RUET-এ পড়ে” → insufficient information. |

| **C01 — Structural locating and layout** | Identify the section/subsection governing content, or interpret meaningful grouping, checkbox states and other structural relationships. | An instruction appears beneath “২.১ অনলাইন আবেদন” within section “২. আবেদন পদ্ধতি।” | “নির্দেশনাটি কোন উপধারার অধীনে?” → ২.১ অনলাইন আবেদন। |
| **C02 — Table interpretation** | Select the correct value using row labels, column headers and units. | Population table: ঢাকা row × নারী column = ১১০; unit = হাজার জন. | “ঢাকার নারী জনসংখ্যা কত?” → ১১০ হাজার জন। |
| **C03 — Charts and infographics** | Interpret graphical marks using labels, legends or scales. | A labeled bar chart shows বরিশাল with the tallest bar. | “চার্টে কোন বিভাগের মান সর্বোচ্চ?” → বরিশাল। Exact values require an adequate scale. |
| **C04 — Maps and spatial relations** | Read direction, adjacency, containment or connections from visual structure. | A map has an explicit north arrow; এলাকা B lies right of a river. | “নদীর পূর্ব পাশে কোন এলাকা?” → এলাকা B। Exact distance would additionally require a scale. |
| **C05 — Counting** | Count a bounded, complete set using a clear inclusion rule. | An order lists three distinct transferred officers, with no printed total. | “কতজন কর্মকর্তাকে বদলি করা হয়েছে?” → ৩ জন। Copying a printed total is direct reading. |
| **C06 — Filtering and set selection** | Return all candidates satisfying an explicit condition. | Complete salary table: সহকারী ১৮,০০০; কর্মকর্তা ২৫,০০০; ব্যবস্থাপক ৩০,০০০ টাকা. | “কোন পদগুলোর বেতন ২০ হাজারের বেশি?” → কর্মকর্তা ও ব্যবস্থাপক। |
| **C07 — Comparison and ranking** | Compare compatible quantities or identify maxima/minima, including ties. | Same-year growth rates: ঢাকা ৫%; খুলনা ৩%; বরিশাল ৩%. | “কোন বিভাগগুলোর বৃদ্ধির হার সর্বনিম্ন?” → খুলনা ও বরিশাল। |
| **C08 — Arithmetic and aggregation** | Calculate a result from supplied operands, associations and rules. | আবেদন ফি ৭০০ টাকা; বিলম্ব মাশুল ১০০ টাকা; both must be paid. | “বিলম্বে মোট কত টাকা দিতে হবে?” → ৮০০ টাকা। No unstated tax or fee may be added. |
| **C09 — Temporal reasoning** | Derive durations, event order or other temporal relationships. | Same-day departure ৯:২০ and arrival ১১:০৫. | “যাত্রার সময় কত?” → ১ ঘণ্টা ৪৫ মিনিট। Merely copying departure time is direct reading. |
| **C10 — Units and numerical normalization** | Convert numerical representations using supplied or benchmark-declared equivalences. | বরাদ্দ ০.২৫ কোটি টাকা; declared equivalence: ১ কোটি = ১০০ লাখ. | “বরাদ্দ কত লাখ টাকা?” → ২৫ লাখ টাকা। |
| **C11 — Conditions and exceptions** | Apply a stated rule to all necessary case facts, including applicable exceptions. | Complete eligibility rule: age ≥১৮ and GPA ≥৪.০০; case: age ১৯, GPA ৪.২০. | “প্রার্থী কি যোগ্য?” → হ্যাঁ। Missing decisive case facts can make the decision unanswerable. |
| **C12 — Entity and record binding** | Associate an attribute with the correct entity or record among plausible alternatives. | Posting table: রহিম—ঢাকা→রাজশাহী; করিম—রাজশাহী→খুলনা. | “করিমের নতুন কর্মস্থল কোথায়?” → খুলনা। রাজশাহী appears but belongs to the wrong attribute. |
| **C13 — Cross-element association** | Connect separate elements whose relationship is necessary to answer. | Fee table: বার্ষিক ফি* ১,০০০ টাকা; linked footnote: আবাসন অন্তর্ভুক্ত নয়. | “এই ফির মধ্যে আবাসন আছে?” → না। Evidence includes the fee entry, marker and footnote. |
| **C14 — Bounded synthesis** | Combine explicit propositions into an explanation with a finite coverage rubric. | Different sections require form completion, ID upload and payment after submission. | “আবেদন সম্পন্ন করতে কী করতে হবে?” → ফরম পূরণ, পরিচয়পত্র আপলোড এবং জমার পর ফি পরিশোধ। |
| **C15 — Amendment and conflict reconciliation** | Interpret competing statements using explicit scope or precedence; flag unresolved conflict. | Original deadline ২০ অক্টোবর; amendment explicitly replaces it with ২৫ অক্টোবর. | “চূড়ান্ত সময়সীমা কত?” → ২৫ অক্টোবর। A later date alone does not establish precedence. |
